# AI State Doctrine

Canonical architecture doctrine defining state preservation,
governed authorization, execution boundaries, and consequence integrity.

## Core Principle

> ONE STATE → ONE CONSEQUENCE

When reality is uncertain, the system does not guess.

It preserves the state until reality can be reconciled.
